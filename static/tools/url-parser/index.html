About URL Encoding

Percent-Encoding

URLs can only contain a limited set of characters. Reserved characters like &, ?, =, and spaces must be percent-encoded (e.g., space → %20).

encodeURI vs encodeURIComponent

encodeURI preserves URL structure. encodeURIComponent encodes everything, ideal for query parameter values.

Quick Reference

  • %20 → space
  • %26 → &
  • %3D → =
  • %3F → ?
  • %2F → /
  • %23 → #
