About this tool

This utility generates UUID v4 identifiers using the browser's crypto.randomUUID() API (with a secure fallback), and computes MD5, SHA-1, SHA-256, and SHA-512 hashes entirely client-side. Nothing is sent to a server — all processing happens in your browser.

Quick Tips

  • UUID v4 has ~122 bits of randomness.
  • MD5 is fast but not collision-resistant — avoid for security.
  • SHA-256 is recommended for integrity checks.
  • All hashing runs locally in your browser.
