How it works

The tool parses your input as an IPv4 or IPv6 address with a CIDR prefix. It computes the network address by masking the host bits, then derives the broadcast (last) address, the usable host range, and the total number of addresses in the block.

Note: For IPv4, the network and broadcast addresses are excluded from "usable hosts". For IPv6, all addresses in the block are considered usable (no broadcast concept).
